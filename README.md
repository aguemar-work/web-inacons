# INACONS - Sitio Web Corporativo

## Descripción del Proyecto
Sitio web corporativo para INACONS, empresa especializada en servicios de ingeniería, construcción y consultoría.

## Principios de Diseño

### Paleta de Colores
- **Primario**: #1a365d (Azul corporativo)
- **Secundario**: #2d5a87 (Azul medio)
- **Acento**: #4a90b8 (Azul claro)
- **Texto**: #2d3748 (Gris oscuro)
- **Fondo**: #ffffff (Blanco)

### Tipografía
- **Principal**: 'Poppins', sans-serif
- **Secundaria**: 'Inter', sans-serif
- **Tamaños**: Sistema de escala tipográfica responsiva

### Sistema de Espaciado y Grid
- **Grid**: Sistema de 12 columnas responsivo
- **Espaciado**: Múltiplos de 8px (8, 16, 24, 32, 48, 64px)
- **Breakpoints**: 
  - Mobile: 320px - 767px
  - Tablet: 768px - 1023px
  - Desktop: 1024px+
